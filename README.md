# Selenium Test Automation Project

A simple Selenium test suite for automated frontend testing.

## Overview

This project contains automated tests for a web application using Selenium WebDriver.

## Tests Included

The test suite includes three functional tests:

1. **Homepage Test** - Verifies the homepage loads correctly and displays "Home" as the title
2. **Contact Page Test** - Validates the contact page navigation and "Contact Us" title
3. **Email Signup Test** - Tests the email subscription functionality and confirmation message
